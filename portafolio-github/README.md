# Portafolio personal
HTML5 + CSS3 + JavaScript + PHP/MySQL. Secciones: Inicio, Nosotros, Galería, Testimonios, Contacto.

## Antes de subir
1. Busca "TU NOMBRE", "TU CARRERA", etc. en index.html y cambia por tus datos.
2. Pon tus fotos en img/ (trabajo1.jpg ... trabajo6.jpg).
3. Cambia los testimonios por reales (compañeros y docentes).

## InfinityFree
1. Panel > MySQL Databases: crea la base "portafolio". Abre phpMyAdmin y ejecuta database.sql.
2. Edita envio.php con tu host, usuario, contraseña y base.
3. Sube todo a htdocs por File Manager o FTP. Prueba el formulario en línea y revisa la tabla "formulario" en phpMyAdmin.

## GitHub
IMPORTANTE: no subas tu contraseña real. Antes del commit deja los datos de envio.php como están en la plantilla, o ponlos en un archivo aparte incluido en .gitignore.
git init && git add . && git commit -m "Portafolio" && git branch -M main && git remote add origin URL && git push -u origin main
